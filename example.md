## About This Blog

This blog was created as part of a master’s assignment focused on cloud computing. One of the main goals of the task was to learn how to build and deploy a personal website using Jekyll and GitHub Pages.

Through this hands-on exercise, I explored how modern web technologies can be used to create and host static websites without the need to manage complex server infrastructure. GitHub Pages, as a Platform as a Service (PaaS), allows users to publish content directly from a repository, making the process simple and accessible.

This website is hosted using GitHub Pages, which handles the deployment process once the content is uploaded to the repository. This demonstrates how cloud-based platforms simplify web hosting and make it accessible to anyone with basic technical skills.

Please note that this blog was created for academic purposes only, as an example of what can be achieved.
